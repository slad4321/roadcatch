# 로드캐치 개발용 서버

지금은 위험 후보 좌표를 주소(예: "신사동 도산대로")와 도로 종류로 바꿔 주는 일만 합니다. 나중에 여러 차량의 후보를 모아 교차 확인하는 기능이 여기에 들어갑니다.

## 실행

```bash
python3 server.py
```

- 포트 8790 (`GILZIKIM_PORT`로 변경 가능)
- 표준 라이브러리만 사용해서 설치할 것이 없습니다.
- 앱 debug 빌드는 `http://127.0.0.1:8790`으로 접속합니다. Pleos 에뮬레이터 이미지는 네트워크가 없어서(기본 네트워크 없음, `10.0.2.2` 응답 없음) adb로 포트를 연결해야 합니다. 에뮬레이터를 켤 때마다 한 번 실행하세요.

```bash
adb reverse tcp:8790 tcp:8790
```

## API

`POST /v1/places`

```json
{"points": [{"id": "c1", "lat": 37.5165, "lon": 127.0203}]}
```

응답:

```json
{"places": {"c1": {"name": "신사동 도산대로", "area": "신사동", "road": "도산대로", "roadType": "secondary", "jurisdiction": "local"}}}
```

- `jurisdiction`: `expressway`(고속도로 계열) 또는 `local`(일반도로). 신고 창구를 고르는 **참고값**입니다. 올림픽대로 같은 도시고속도로도 `expressway`로 나오지만 실제 관리는 지자체 기관입니다.
- 주소를 못 받은 지점은 응답에서 빠지고, 앱은 "출발 후 거리"로 표시합니다.

- `agency`: 피해 배상 청구처 **참고값**. 고속도로면 `한국도로공사`, 아니면 구청 이름(예: `강남구청`). 국도나 도시고속도로는 관리 기관이 따로 있어 실제와 다를 수 있습니다.

`GET /v1/tiles/{z}/{x}/{y}.png` → 지도 타일(256px)

- OpenStreetMap 표준 타일을 받아 `.tilecache/`에 저장해 두고 돌려줍니다. 앱이 회색으로 바꿔 그립니다.
- OSM 타일 정책상 개발용 소량 사용만 됩니다(식별 User-Agent, 캐시, 출처 표기). 운영에서는 브이월드·카카오·네이버 같은 계약 제공자로 바꿔야 합니다. CARTO 회색 지도는 이제 키가 필요하고, Esri 회색 지도는 한국 데이터가 없습니다.

`GET /health` → `{"ok": true}`

## 주소 변환 제공자

- 지금: OpenStreetMap Nominatim. 키가 필요 없지만 **초당 1건 제한**이 있고 개발용입니다. 서버가 요청 간격을 1초로 맞추고, 약 11m 단위로 결과를 캐시합니다.
- 운영: 키가 필요한 브이월드(국토부)나 카카오로 `reverse()` 함수만 바꾸면 됩니다.
- 좌표가 서버와 제공자에게 전달되므로, 운영 단계에서는 위치정보 동의와 처리방침에 이 내용이 들어가야 합니다.
